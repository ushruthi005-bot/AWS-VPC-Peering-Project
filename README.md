## 📌 Linux Networking & Ping Command Tutorial

### Overview
In this task, we cover the fundamentals of testing network connectivity between servers and cloud instances using the Linux `ping` command and its essential flags.

### Key Concepts Covered:
* **ICMP Echo Requests & Replies**: Testing reachability between two hosts.
* **Ping Flags & Options**:
  * `-c <count>`: Limit the number of packets sent.
  * `-i <interval>`: Set interval between packets.
  * `-s <packetsize>`: Specify packet payload size.
  * `-t <ttl>`: Set Time to Live value.
  * `-4` / `-6`: Force IPv4 or IPv6 protocol.
  * `-f`: Flood ping (for stress testing).
